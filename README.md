Based on [will-you-be-my-valentine](https://github.com/saurabhnemade/will-you-be-my-valentine) by saurabhnemade

## Run locally
```bash
npm install
npm run dev
```

Then open http://localhost:5173/joey-valentines

## Deploy to GitHub Pages
```bash
npm run deploy
```

Site live at: https://yeowokay.github.io/joey-valentines

## Update after making changes
```bash
git add .
git commit -m "Describe your changes"
git push
npm run deploy
